工作原理

命中规则
  1. ClientHello
  2. 原始 SNI
  3. Snirect 本地 CA 中转
  4. 改写/剥离 SNI
  5. 目标前置 IP
常规站点
  1. ClientHello
  2. TCP 原样透传 · 零解密
  3. 远端服务器

克制而可靠

静态内置规则

同步适配自 Cealing-Host，编译期静态编入二进制，运行时零联网拉取。

按需无感分流

仅命中规则的 443 连接经本地 CA 中转，其余流量原样透传，支持自定义 PAC。

内建加密 DNS

内置 DoH 与 DoT 解析，通过纯 IP 引导解析防止回环，支持缓存与 ECS。

全平台轻量运行

支持 Linux、macOS、Windows 用户态后台服务，以及基于 VpnService 的 Android 客户端。

快速开始

paru -S snirect-bin          # Arch Linux (AUR)，或从 Releases 下载二进制
snirect cert install         # 生成并信任根证书
snirect service install -s   # 注册用户服务并设置系统 PAC
chmod +x snirect-darwin-arm64 && sudo mv snirect-darwin-arm64 /usr/local/bin/snirect
snirect cert install
snirect service install -s   # LaunchAgent，无需 root
Rename-Item snirect-windows-amd64.exe snirect.exe
snirect cert install
snirect service install -s   # HKCU\...\Run，无需管理员

通过 VpnService 与 gVisor netstack（10.0.0.2/24）复用核心代理流水线，并在触发 OnCertRejected 时自动排除证书固定应用。
